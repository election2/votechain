# 🗳️ VoteChain

A modern mobile-friendly digital voting prototype.

## Features

- 🪪 Identity document selection
- 📷 Front camera access
- 👤 Liveness prototype
- 🗳️ Party voting
- ✅ Vote confirmation
- 🧾 Vote receipt
- 🚫 One-vote browser demo protection
- 📊 Election results
- 📱 Mobile responsive UI

## Run

Open the project using a local server or deploy with GitHub Pages.

## Important

This project is a prototype.

It is NOT suitable for government or public elections.

Real election systems require:

- Secure backend
- Audited voter verification
- Privacy-preserving ballots
- Secure authentication
- Independent security audits
- Legal compliance
- Accessibility support
